    ℹ️ Metodologi & Transparansi Data

    Panduan lengkap mengenai tata cara pengambilan data, anonimisasi privasi, formula matematis, batasan sistem, dan etika Human-in-the-Loop.

    📡

    1. Cara Pengambilan Data & Kepatuhan ToS

    Data ditarik secara berkala untuk kurun waktu 7 hari terakhir (window_days: 7) menggunakan YouTube Data API resmi serta scraper multi-platform (Instagram, TikTok, Threads, Facebook) dengan pembatasan frekuensi (rate-limiting) yang wajar.

    Untuk platform dengan akses ketat, tersedia jalur alternatif berupa loader berkas (data/weekly_input/) yang mendukung format CSV dan JSON tanpa melanggar ketentuan layanan (Terms of Service) penyedia platform.

    🔒

    2. Privasi & Anonimisasi Identitas

    Untuk mematuhi etika riset dan regulasi pelindungan data pribadi (UU PDP), identitas pengguna media sosial tidak pernah disimpan dalam format teks polos (plain text).

    • Username publik dianonimkan menggunakan algoritma satu arah SHA-256 menjadi format user_xxxx.
    • Penyebutan nama akun (mention @username) dalam teks komentar diganti secara otomatis menjadi @pengguna.
    • Akun resmi institusi (seperti @undiksha) tetap ditandai melalui flag is_official agar data pengumuman dapat dipisahkan dari opini murni publik.
    📐

    3. Formula Matematis & Penilaian Isu

    Indeks Reputasi Kampus:
    I = (P - N) / (P + N + 0.5 * O)
    Menghasilkan skor antara -1.0 (sangat negatif) hingga +1.0 (sangat positif).

    Rasio Lonjakan Isu (Growth Ratio):
    Growth = (V_minggu_ini + 1) / (Mean(V_4_minggu_sebelumnya) + 1)
    Menggunakan Laplace Smoothing agar tidak terjadi pembagian dengan nol pada topik baru.

    Skor Isu Terbobot (Issue Score 0 - 100):
    Skor = (0.30 * V_norm + 0.45 * P_negatif + 0.25 * Growth_norm) * 100
    Tingkat Perhatian: Tinggi (≥65), Sedang (≥40), Rendah (<40).

    ⚖️

    4. Batasan Sistem & Human-in-the-Loop

    Sistem analisis ini dirancang sebagai alat bantu pemantauan dini (indicative decision support) bagi pimpinan universitas dan UPT TIK / Humas, bukan pengambil keputusan mutlak secara otomatis.

    PENTING: Hasil klasifikasi sentimen AI dan deteksi isu bersifat indikatif. Jika jumlah data mingguan di bawah ambang minimum (min_mentions: 5), sistem menampilkan tanda Data Terbatas untuk mencegah kesimpulan yang menyesatkan. Verifikasi konteks nyata oleh tim humas manusia tetap menjadi rujukan utama.
